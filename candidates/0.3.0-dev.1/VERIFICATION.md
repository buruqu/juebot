## 本轮实际实现

- 持久记忆策略：隔离/共享及每流限制、来源与派生链、用途/目标/期限约束、上下文失效、显式撤源。共享只允许获准通用学习，私聊事实和Code材料不自动流入其他会话或公开创作。
- 两种身份独立档案、自我状态、情绪衰减、兴趣/关系、有限参与与主动意愿；成长候选、评测合同、人审激活和版本恢复。角色核心修改属于管理操作。
- 可信入站→经历→记忆/状态→模型草稿→表达检查与有限重写→打字计划→持久Outbox→发送前复核。多人复读使用验证过的原文，零额外打字等待并绕过普通打字队列，仍受真实发送锁、权限和频率限制。
- 同一canonical账号的聊天、Code结果与创作共用发送锁，审批消费和入队同事务；默认暂停、预算预留、幂等、租约与unknown保留。外发默认25秒截止并传取消信号，超时为结果不明，不能视为未提交或自动重发。
- Code OFF拒绝新任务，当前running继续；未验证管理员、缺沙盒/预算/工具限制不得启用。执行器由可信Host提供，候选没有实际操作系统沙盒执行器。
- 原生管理面板候选：会话、消息正文、决策/投递记录、局部/全局设置、记忆与来源撤销、身份、学习/成长、作品最终审核、出站和Code状态。后台展示可核对的选择及结果，不存模型私有思维链。
- 创作意愿→公开材料→方案/脚本→成品→人审→提交意图。QQ空间、B站评论/回复/动态/视频全都审核最终内容、账号、目标、完整资产及来源；意愿本身的来源也在公开用途授权交集中。改变内容、身份、资产或来源使旧审批失效。
- 实际本地视频工具生成有限文字卡/静音MP4、PNG封面、WAV和VTT；端到端测试使用合成模型JSON产生分镜，真实ffmpeg渲染成片。没有TTS、音乐、复杂剪辑、真实视频生成模型或平台上传。
- 独立SQLite应用工厂、owner路由适配、显式启动runner、迟到订阅清理和在途排空；默认禁用且不打开数据库。初始化路径拒绝源码/安装树、软硬链接以及异常SQLite sidecar。

模型端口按[DeepSeek官方chat-completions合同](https://api-docs.deepseek.com/api/create-chat-completion/)实现显式JSON请求、有界响应、预算回调、取消与禁止重定向；测试只使用合成fetch和本地回环，不表明真实模型兼容、质量或计费已验收。
